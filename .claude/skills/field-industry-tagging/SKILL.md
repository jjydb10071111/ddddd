## F2 — 학문분야 (PRD 8.2)

- [ ] 모든 과목에 학문분야 태그 1개 이상 (대분류-소분류 체계, 예: 자연과학 > 수학 > 해석학)
- [ ] 초기 태깅은 AI 1차 분류 + **담당자 검수 후 확정** — AI 태그를 검수 없이 바로 노출하지 말 것
- [ ] 검색 결과는 **"과목명 일치"**와 **"분야: X"** 두 그룹으로 분리 표시 (하나로 합쳐서 랭킹하지 말 것)
- [ ] 동의어 사전(수학 ↔ 수리과학) 적용
- [ ] 학점/학년/개설학과/평점/리뷰수 필터·정렬
- [ ] 한 과목이 복수 분야에 속할 수 있음 (예: 데이터구조 → 컴퓨터공학 + 수학)

## F3 — 산업/진로 분야 (PRD 8.3)

- [ ] F2와 **별도 축**의 산업/진로 태그셋 (반도체, AI·데이터사이언스, 바이오·헬스케어, 금융·핀테크, 콘텐츠·미디어...)
- [ ] 과목-산업태그는 다대다 + **연관도 스코어**(임베딩 유사도 기반, pgvector) — 이진 태그 아님
- [ ] AI 스코어링 + 담당자 검수 후 확정
- [ ] 결과는 연관도 순 정렬, 개설학과/학점/이수구분(전필·전선·교양) 표시 필수
- [ ] 사용자 소속 학과 기준 **"내 전공 과목" vs "타 전공 과목"** 구분 표시, 타 전공은 정원/선수과목/학년 제한 가능성 안내
- [ ] 신조어/신산업 분야 등장 시 유연하게 태그 확장 가능한 구조 (태그를 코드에 하드코딩된 enum으로 만들지 말 것)

## 아키텍처 메모 (PRD 10.3)

과목명 검색은 Postgres 텍스트 검색, 분야 매칭은 태그 조인 테이블로 우선 구현 후 pgvector 임베딩으로 고도화. 임베딩 생성은 `review-ai-summary`와 동일한 LLM API 경로 재사용 — 중복 구현 금지.

깊은 구현(스키마 조인, 태깅 파이프라인 등 여러 파일)은 `field-industry-search` 에이전트에 위임하세요.
