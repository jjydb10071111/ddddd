## 체크리스트 (PRD 8.1)

- [ ] 리뷰 작성: 별점(5점) + 자유 텍스트 + **고정된** 해시태그 세트 다중 선택 (#꿀강의 #널널함 #과제많음 #팀플많음 #출석중요 #시험어려움 #교수님친절 #실무중심 #재수강비추 — 새 태그를 임의로 추가하지 말 것)
- [ ] AI가 자유 텍스트에서 해시태그 **후보**를 추천, 사용자가 채택/수정 (자동 확정 금지)
- [ ] 과목별 요약은 **3~5문장**, 전반적 평가 경향 + 대표 장단점 + 추천 대상을 포함
- [ ] 리뷰 5개 미만 → "리뷰가 아직 충분하지 않습니다" 안내, 요약 생략/제한
- [ ] 신규 리뷰 누적 시 요약 **재생성** (매번 재생성 아님 — Summary 엔티티에 캐시)
- [ ] 해시태그별 언급 빈도(%)를 과목 상세 페이지에 표시
- [ ] 동일 사용자 반복/도배성 리뷰, 평점 테러 탐지·필터링 로직 존재

## Edge case

- 리뷰가 극단적으로 갈림 → "호불호가 갈리는 강의" 명시 (평균으로 뭉개지 말 것)
- 신규 개설·리뷰 0개 → "첫 수강평을 남겨보세요"

## 아키텍처 메모 (PRD 10.3)

리뷰는 Route Handler → Neon 저장. 요약 생성은 서버사이드 LLM API 호출 (`vercel:ai-sdk`/`vercel:ai-gateway` 스킬로 실제 provider 연동 — 직접 SDK를 새로 짜지 말 것). 생성이 느리면 리뷰 제출 응답을 막지 말고 비동기로 처리.

깊은 구현(여러 파일, 스키마 연동 포함)은 `ai-review-summarizer` 에이전트에 위임하세요.
